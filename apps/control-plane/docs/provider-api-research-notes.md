## Selection posture

The documented-fit candidates are **Paystack** for NGN/KES/ZAR payment and transfer primitives, **M-PESA Daraja** for Kenya-only mobile-money rails, **Onafriq** for account-validation, payout, and rate-query boundaries, and **Kotani Pay** for explicitly configured crypto-fiat/stablecoin-adjacent provider discovery and quote flows. Flutterwave and Thunes remain documented candidates pending endpoint-level and account-entitlement validation. None should be activated or represented as licensed, connected, available, settling, or CBN-approved without authorised counterparty evidence, deployment secret references, and applicable regulatory approval.

## Direct documentation verification

On 2026-08-19, the reviewed Paystack API overview stated that all requests use HTTPS, that the secret key is supplied as a bearer authorisation header, and its supported-currency table listed NGN/Nigeria, KES/Kenya, and ZAR/South Africa. The same documentation distinguishes test and live API keys. The reviewed Kotani Pay v3 overview states that its sandbox is for development and testing with no real money movement, identifies separate sandbox and production base URLs, and describes API-key bearer authentication. It describes deposits, withdrawals, on-ramp, off-ramp, and webhooks, but this is product documentation—not evidence that a UmojaFlowOS account has production rights, a configured provider, usable balance, or any regulatory permission.
