02 / verification flow
Five gates before promotion admission
The path is deterministic, auditable, and terminal on ambiguity.
01

Canonical payload

Sort manifest keys, serialize deterministically, bind role and release SHA.

02

Ed25519 proof

Decode 32-byte key and 64-byte signature; verify detached payload.

03

Certificate path

Build bounded chain, detect cycles, enforce CA constraints and pinned anchor.

04

Revocation state

Validate signed CRL, responder identity, OCSP signature, status, serial, and freshness.

05

Promotion decision

Only a complete four-role result can reach canary or production rollout.

Any error → AuthorizationError → nonzero exitPromotion remains blocked; settlement is never opened automatically.
