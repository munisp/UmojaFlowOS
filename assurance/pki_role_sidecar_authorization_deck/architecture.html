01 / authorization architecture
Trust is a chain, not a signature
Every approval must survive independent identity, key, path, and revocation checks before release admission.
01

Manifest approval

Role, subject, release SHA, and approval timestamp are machine-bound to the release evidence manifest.

02

Ed25519 sidecar

Detached signature covers the canonical manifest payload, role, subject, and immutable release SHA.

03

PKI path

Public-key digest binds to the external directory; responder chains terminate at a pinned SHA-256 trust anchor.

04

Revocation state

Signed CRL and current OCSP status reject revoked, unknown, stale, malformed, or untrusted identities.

Fail-closed invariant: ambiguity at any stage blocks promotion.
Required roles: release_manager · security_owner · compliance_owner · operations_owner
