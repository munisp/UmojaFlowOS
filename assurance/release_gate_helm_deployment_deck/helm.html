Deployment Automation
Helm Encodes the Production Preconditions

Immutable Image Gate

Enforces full SHA-256 digests. Rendering fails if mutable tags or placeholders are used, preventing unverified code promotion.

Signed Evidence PVC

Mandatory read-only mount of the release bundle. Replicas cannot start without the manifest and four detached signatures.

Vault & Storage Wiring

Automated binding for version-aware credential refresh and S3/GCS canary validation. No secrets are stored in the chart.

OTel & Pool Controls

Standardized OTLP endpoints and PostgreSQL pool limits per replica to ensure observability and database stability.

Fail-Closed Rendering: The chart intentionally lacks default values for security-critical fields, requiring explicit, validated overrides for every production release.
