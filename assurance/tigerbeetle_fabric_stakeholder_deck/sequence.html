Process Flow
A settlement becomes an auditable proof
1. Bind
Immutable payload SHA-256 bound to idempotency key in PostgreSQL.
2. Post
Authoritative double-entry transfer created in TigerBeetle.
3. Attest
Consortium endorsement of the evidence digest in Fabric.
4. Reconcile
Read-only status query resolves any network timeouts.
The Golden Rule:No blind retries. No second ledger postings. No ambiguous outcomes.
