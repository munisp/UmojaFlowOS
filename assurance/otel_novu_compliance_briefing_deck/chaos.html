05 / Resilience Validation

Chaos testing is safe by design

1. Non-Destructive Preflight

  • Validates Toxiproxy API reachability without network changes.
  • Verifies Kafka and Temporal proxy inventory existence.
  • Confirms local-only endpoint restrictions to prevent production leakage.

2. Authorization Gate

  • Requires explicit CHAOS_APPROVED environment token.
  • Mandates named proxy targets for surgical fault injection.
  • Enforces bounded duration (30-300s) with automatic timeout.

3. Fail-Closed Recovery

  • Atomic toxic removal in finally block ensures restoration.
  • Probes Prometheus to verify alert firing during the partition.
  • Zero mutation of ledger data or payment workflow state.

Core Safety Guarantee

The harness never kills processes or retries payments blindly. If the observer fails or the proxy is unreachable, the test fails closed and settlement remains fenced.
