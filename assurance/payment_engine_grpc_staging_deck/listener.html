03 · Runtime Security
8443 Is Exposed Only With Fail-Closed Startup
The payment-engine binary enforces transport security at the entry point. Opening the socket does not enable settlement execution.
Go Runtime Wiring

Concurrent Listener Startup

The binary reads GRPC_SETTLEMENT_LISTEN_ADDR to start the gRPC server alongside the existing HTTP server. Graceful shutdown is enforced for both.

Mounted mTLS Material

Certificates are mounted read-only from Kubernetes secrets. The loader enforces strict file permissions and valid chain verification.

/var/run/umoja-settlement-grpc/ca.crt
/var/run/umoja-settlement-grpc/tls.crt
/var/run/umoja-settlement-grpc/tls.key
Security Safeguards

TLS 1.3 & Client Auth

The server requires and verifies client certificates. TLS 1.3 is the minimum version, ensuring modern cipher suites and perfect forward secrecy.

Fail-Closed Execution

Until the real settlement coordinator is composed, the handler is hard-coded to return UNKNOWN. Exposing the port is safe by design.

GRPC_SETTLEMENT_EXECUTION_ENABLED=false
Posture: Transport optimization is decoupled from execution authority; no ambiguous state can trigger a payment.
